# Sidebar Artwork

The sidebar header can carry a piece of artwork. It fills the space behind the Piku Code
wordmark and also colors the send button in the message composer.

Pick one in **Settings → Appearance → Sidebar artwork**. There are eight scenes to choose
from — the two classic channel scenes (Night Sky and Blueprint) plus six illustrated
landscapes (Aurora, Dusk Tide, Midnight City, Misty Pines, Nebula, and Neon Horizon). A
choice applies everywhere: every environment, light and dark themes.

**Auto** is the default and keeps the long-standing behavior: Dev environments show
Blueprint, Nightly shows Night Sky, and production stays plain. Auto also respects the
**Environment identification** setting — switch that to the version pill or to none and no
artwork appears. An explicitly chosen artwork always shows, regardless of channel or the
environment identification mode.

The picker previews exactly what the Auto choice resolves to on the current environment, so
you can see what you will get before you commit. Use the reset arrow next to the setting
title to return to Auto.
